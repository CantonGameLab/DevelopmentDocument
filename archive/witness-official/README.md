# The Witness 官方开发博客（the-witness.net/news）

Toby/Number None → Thekla, Inc. 的开发日志，2010–2022 年持续更新。本目录收 RSS 全文 feed 窗口内的 **100 篇**。
这是理解《The Witness》开发过程最一手、最完整的资料：早期是引擎技术文章，中期是美术与设计决策，后期是上市前后的复盘。

- 站点：<http://the-witness.net/news/>
- 抓取方式：站点 RSS 全文 feed（`/news/feed/`），正文为全文而非摘要
- 抓取篇数：100（覆盖 2012-10 至 2022-02）
- 时间跨度：2012-10-14 → 2022-02-10

> **2010–2012 的早期技术文章不在这里。** RSS feed 只回溯到 2012-10，而那批文章（Precomputed Lighting、Lightmap Parameterization、Hemicube Rendering and Integration、Irradiance Caching – Part 1、Shadow Maps 系列…）是《The Witness》光照系统的一手材料，现已补抓，见 **`../witness-graphics/`**（19 篇）。
> 本目录的 100 篇里，有 4 篇是 Casey Muratori 文章的官方交叉发布；wiki 清单层去重后，官方博客条目为 **96** 条。
